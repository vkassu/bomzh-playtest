## Источники и лицензии

- Фон взят из зимней бинауральной записи IHTApark в Ахене. Josep Llorca-Bofí, Jonas Heck, Christian Dreier и Michael Vorländer, RWTH Aachen University. Уровень поднят, крайние частоты ослаблены, шов петли сведён перекрытием. У версии для подъезда верхние частоты ослаблены двунаправленной фильтрацией Баттерворта второго порядка с частотой среза 650 Гц. Прямой и обратный проходы подавляют верхние частоты без фазового сдвига. Частота дискретизации уменьшена с 48 до 12 кГц после фильтрации. Стерео, длительность и точки петли сохранены. [Набор записей IHTApark](https://zenodo.org/records/11184517) · [Исходная зимняя запись](https://paad-group.github.io/IHTApark-ambient-recordings/data/Binaural/20220212_Sat_23h00_Pos3_30sec.wav) · [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
- Пять вариантов шага выделены из записи ботинок по снегу Nox_Sound. Уровни выровнены, края плавно затухают. [Исходная запись шагов](https://freesound.org/people/Nox_Sound/sounds/613849/) · [CC0](https://creativecommons.org/publicdomain/zero/1.0/).
- Открывание и закрывание взяты из записи одной металлической двери помещения с почтовыми ящиками. Автор giddster. Фрагменты переведены в моно, низкочастотный гул приглушён. [Исходная запись двери](https://freesound.org/people/giddster/sounds/336660/) · [CC0](https://creativecommons.org/publicdomain/zero/1.0/).

Шаги и дверь подготовлены из общедоступных версий для прослушивания. Все файлы в WAV PCM, 16 бит. Фон в стерео, шаги и дверь в моно.
