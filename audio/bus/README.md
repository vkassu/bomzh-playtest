# Звук автобуса MAN SG 220

Двигатель записал Dušan Oblak. Work With Sounds / Technical Museum of Slovenia. [Оригинал записи двигателя](https://commons.wikimedia.org/wiki/File:WWS_CityBusMANSG220engine.ogg).

Двери записал Boštjan Troha. Work With Sounds / Technical Museum of Slovenia. [Оригинал записи дверей](https://commons.wikimedia.org/wiki/File:WWS_CityBusMANSG220dooropeningclosing.ogg).

Оригиналы и обработанные записи распространяются по лицензии [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

Исходники нарезаны и отфильтрованы, уровни выровнены. Для двигателя собраны петли с плавными швами. Дверные эффекты переведены в моно. При разметке звука порядок открытий и закрытий сверили с отдельной записью дверей. [Видео дверей MAN SG 220](https://commons.wikimedia.org/wiki/File:City_Bus_MAN_SG_220_%E2%80%93_door_openingclosing.ogv).

| Файл | Длительность | Применение |
| --- | ---: | --- |
| bus-drive-loop.wav | 5,15 с | Двигатель в движении. |
| bus-idle-loop.wav | 4,60 с | Двигатель на холостом ходу. |
| bus-door-open.wav | 2,76 с | Открывание пневматических дверей. |
| bus-door-close.wav | 3,71 с | Закрывание пневматических дверей. |

Все четыре файла в WAV PCM, моно, 48 кГц, 16 бит.
